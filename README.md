# 経済プリント・赤シート

経済プリント1〜15ページを、元PDFの文字・図・余白のままSVGで表示する学習サイトです。追加の政治5枚は含みません。

- 赤シートで全解答を隠す／表示
- タップで個別の答えを確認
- ページ選択、前後の移動、拡大・縮小
- 写真で未記入の欄と、判読が不明な欄の区別
- 解答の確認・修正（端末内に保存）

## 公開

HTML / CSS / JavaScriptのみで動作します。GitHub Pagesの場合は、Settings → Pages → Deploy from a branch → main / (root) を指定します。

ローカルでは、このフォルダーをHTTPサーバーで配信してください。ファイルを直接開く方式では教材のfetchが制限されます。

## データ

`data.json` の解答には写真の転記、写真未記入、判読不明、文脈からの補完を記録しています。補完は茶色で表示します。

元のプリントに印刷済みの語句・説明は原文のままです。内容を現在の法制度・経済状況に更新した教材ではありません。

元の文字はベクターの輪郭として保持し、ページごとのSVGと共通の字形データを読み込みます。PDF埋め込み・ページ画像の拡大表示は使用していません。
